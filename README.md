# Telegram Funding Bot

بوت مهام وتمويل قنوات تيليجرام: المستخدم يكمل مهام الاشتراك الطوعية ويحصل على نقاط، ومالك الحملة يمول المهام بالنقاط.

## أهم المزايا
- /start + إحالات.
- رصيد ونقاط وسجل معاملات.
- إضافة حملات لقنوات تيليجرام.
- زر "تحقق" من عضوية المستخدم عبر Telegram Bot API.
- منع احتساب المهمة مرتين.
- لوحة مالك: إحصائيات، المستخدمون، الحملات، إيقاف/تشغيل البوت.
- أوامر إدارية أساسية.
- SQLite افتراضيًا، ويمكن تغيير DATABASE_URL إلى PostgreSQL.
- لا توجد أي عملية إجبارية لإضافة المستخدمين أو تجاوز حماية تيليجرام.

## التشغيل محليًا
1. ثبّت Python 3.12.
2. انسخ `.env.example` إلى `.env`.
3. ضع توكن البوت في `BOT_TOKEN`.
4. ضع Telegram numeric ID للمالك في `OWNER_ID`.
5. نفّذ:
   `python -m venv .venv`
   ثم فعّل البيئة الافتراضية.
6. `pip install -r requirements.txt`
7. `python -m app`

## مهم جدًا لقنوات المهام
حتى يستطيع البوت التحقق من العضوية، أضفه مشرفًا في القناة المستهدفة مع الصلاحيات اللازمة لقراءة حالة الأعضاء. لا يحتاج إلى إرسال رسائل في القناة.

## رفع المشروع إلى GitHub
من صفحة المستودع:
Add file -> Upload files -> ارفع محتويات المشروع -> Commit changes.
لا ترفع `.env`.

## النشر
يمكن تشغيل Docker على أي استضافة تدعم Docker. لا تعتمد على الخطة المجانية قبل التأكد من شروطها الحالية؛ بعض الخدمات توقف الخدمات المجانية أو تطلب وسيلة دفع.

## الأمان
- لا تضع BOT_TOKEN داخل GitHub.
- إذا انكشف التوكن، ألغِه فورًا من BotFather وأنشئ توكنًا جديدًا.
- OWNER_ID ليس سرًا، لكن لا تستخدم معرفًا غير موثوق.
